Agent Commands 0.1.0 - Windows x64

This package installs 17 command-line tools and an Agent Commands Terminal shortcut.
Open the shortcut to start Command Prompt with the installed commands on PATH.
The PATH change is limited to that terminal session; the installer does not alter
system or user PATH settings.

In PowerShell, add the installation directory to the current session PATH and use
.exe names when a PowerShell alias conflicts, for example curl.exe or ls.exe.
The standalone cd.exe cannot change its parent shell; use the native cd command or
the optional shell\cd.ps1 integration described in README.md.

The tools implement documented subsets of common commands, not full replacements.
Use --help with a command to see the available options. Uninstall using Installed
Apps or the included uninstaller. Modified files can be retained by IronSetup.
