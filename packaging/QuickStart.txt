Agent Commands 0.2.0 - Windows x64

Agent Commands provides Linux-style command-line tools (ls, cat, grep, rg,
find, head, tail, sort, wc, xargs, curl and more). Run "agentcmd --list" in
the Agent Commands terminal to see the full list.

Portable ZIP
Extract the entire ZIP to a folder, then open "Agent Commands.cmd" in that
folder. The launcher starts Command Prompt with the tools on PATH for that
session. To remove the portable copy, close the terminal and delete the folder.

Windows installer
After setup, open "Agent Commands Terminal" from the Start menu. If you chose
"Add the install directory to my user PATH", new terminals can also find the
commands directly. Uninstall from Installed Apps or the Start menu to remove
the installed tools and the optional PATH entry.

In PowerShell, use .exe names when a PowerShell alias conflicts, for example
curl.exe or ls.exe. The standalone cd.exe cannot change its parent shell; use
the native cd command or the optional shell\cd.ps1 integration described in
README.md.

The tools implement documented subsets of common commands, not full
replacements. Use --help with a command to see the available options.
